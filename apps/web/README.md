# Primq Web App

This is a placeholder for the web application built with Next.js.

## Getting Started

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- Shared components from `@primq/ui`
- Shared hooks from `@primq/hooks`
- Shared API clients from `@primq/api`
- Shared types from `@primq/types`
